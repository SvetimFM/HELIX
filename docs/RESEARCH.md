# Experimental evidence and reproducibility

## What was executed now

`node --test tests/*.test.mjs` runs deterministic tests including 2,000 random permutations for canonical codec round trips, well-typed relations, algebraic laws in supported cases, scoped perspectives, gluing classifications, and an odd-cycle relational obstruction. This validates *specific executable behaviors*, not a universal neural theory of experiential language.

`python tests/browser_smoke.py` checks the grammar/editor in headless Chromium at desktop, tablet and phone viewports; runs edit→serialize→decode; creates typed nodes and relations, transfers the resulting scene into the earlier musical synthesizer, and checks that playback starts. The test embeds the module into the page to work around this sandbox's network restrictions, so HTTPS navigation and localStorage handoff must also be verified after actual web hosting. There has been no device-level Safari validation.

## Previous numerical work

See `EXPERIMENT_V02.md`, `gluing_experiment_results.json`, and `music_experiment_results.json`. These were executed during earlier HĒLIX prototype work and are retained as exploratory evidence. The finite model supports the basic distinction between agreement on overlapping descriptions and existence of a global relational solution. The music tests support structure-preserving transposition/tempo/timbre in a **specified renderer**, not the recovery of subjective experience from sound.

## Hypotheses that remain untested

1. Trained vector encoders might approximate HGL's typed relational composition.
2. Musical phase, timbre, interval, and contrapuntal invariants might carry observer-relevant structural information across different performances.
3. Independent human judges might recover relational meaning from musical performances above chance under blinded controls.
4. The most expressive HĒLIX might allow locally contradictory perspectives while preserving globally tractable uncertainty without an assumed closed-world ontology.

These are hypotheses, not results. Distinguish symbolic structural round trips from the much harder audio-only inference problem.
